# Study Portal — 25–26

A polished, static, link-only study library.

## Run locally

1. Open a terminal in this folder.
2. Run `python -m http.server 8000`.
3. Open `http://localhost:8000` in Chrome.

The portal includes only collected lecture links. Materials/PDFs/books/notes are intentionally empty, 26–27 courses are deferred, and Chemistry is excluded.

## Features
- Subject → course → chapter → topic → video navigation
- Search across the full link library
- Mobile responsive layout
- Light/dark theme toggle
- Original YouTube links open in a new tab
- No external JavaScript dependencies
